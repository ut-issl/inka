# inka — Web UI

対話的なグラフビューアが保つ不変条件。ビューアは論証の read-only な可視化であり、
他のすべての出力と同じ共有モデルの上に成り立つ。
英語版(正): [English](https://www.space.t.u-tokyo.ac.jp/inka/design/web-ui/)

## 基盤

- ビューアは共有の論証ビュー(Markdown レポートと同じ read-only 投影)を、`inka export`
  の cytoscape `elements` JSON として描画する。論証をパースも変更もしない。
- 厳密に read-only: UI 内のどこも、論証・承認・その他の状態を変える操作へリンクせず、
  発火もさせない。
- 論証は DAG である。各ノードは 1 回だけ現れ、複数の親を持つノードは辺で表し、複製
  しない。
- 描画は決定的: ノードの同一性と順序はビューのソート済み block-ID 順に由来し、同じ
  プロジェクトは常に同じグラフを描く。
- 実装: レンダラは単一の TypeScript フロントエンドバンドル(`web/`。これらの不変条件の
  唯一の実装)であり、`inka serve`(Rust)が `inka export` の cytoscape JSON とともに配信
  する。グラフライブラリはバンドルにベンダリングされ、inka の一部ではない。

## レイアウト

- 全体表示: トップダウンの層状 DAG — objective が最上位、辺は下へ流れる — なので、
  上位の要求が常に見分けられる。
- ノードフォーカス: 直接の親が上、フォーカスしたノードが中央、直接の子が下。
- namespace フォーカス: その namespace のノードと、1 親等離れた全ノードを、トップダウン
  に配置する。
- どのランク内でも、同一 namespace のノードが隣接するように並べ、その namespace の順序
  はランク間で一貫させる(namespace がほぼ縦帯として読める)。
- レイアウトしたグラフの縦横比は、フォーカス時・全体表示時を問わず常にグラフウィンドウ
  に一致する。一致は短い軸を引き伸ばすだけで、圧縮は決してしない(ノードが新たに重なら
  ない)。

## ノード

- ノードの形と塗りは discharge モード(objective / structure / bind / fiat)を符号化し、
  4 つは視覚的に区別できる。
- ノードはラベルにオートサイズする。
- ラベルはノード id。description をノード内に描画することはない。

## 辺

- すべての辺は同じ太さで描く。
- 辺は親から各子へ向かう(矢頭は子側)。

## namespace

- namespace は各ノード上の色付きバッジとして、全状態で表示する。囲みや枠線はない。
- バッジは一定ズーム未満では非表示で、ズームインで現れる。
- namespace はどちらの面からもフォーカス対象になる: グラフ上のノードのバッジ、および
  一覧の namespace 見出し。
- namespace 解決が入るまで、ノードの namespace は論証ファイルの stem とする。

## フォーカスと操作

- フォーカス対象は、単一ノード(→ そのノードと直接の親・子)と namespace(→ その
  メンバーと 1 親等の近傍)の 2 つだけ。
- 「1 親等」は直接の親と子のみを指す。
- Esc、または空白の背景のタップで、フォーカスを解除して全体表示に戻す。

## ノード一覧

- 一覧は全ノードを namespace ごとにグループ化して含む。グループはトポロジカル順、
  グループ内のノードもトポロジカル順。
- ノード項目のクリックでそのノードを、namespace 見出しのクリックでその namespace を
  フォーカスする。
- フォーカス時、関連する項目を強調する — 親を一方の色、子をもう一方の色で — し、
  フォーカスしたノードまたは namespace を目立たせる。
- 一覧とグラフは構造と順序について一致する。どちらも共有ビューに由来する。

## 詳細

- ノードのホバーで、その description 全文を表示する。
- ノードの選択で、その契約・証拠ターゲット・期限を表示する。

## 不変条件ではないもの

- 色、ズーム閾値、バッジのサイズ、間隔、ノード寸法は表示パラメータであり、自由に調整
  する。不変条件ではない。
